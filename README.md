# Brewed Space ☕️

A modern table booking and reservation platform for **Brewed Space**. This application is designed to provide a seamless user experience for customers to book their spot, whether it's for hanging out, meetings, or remote work (WFC).

## 🚀 Features

- **Intuitive Booking Form**: Simple and fast table selection process.
- **Automated Notifications**: Instant email confirmation sent to customers after a successful booking.
- **Modern UI**: Sleek, dark-themed design with gold accents to match the Brewed Space brand.
- **Responsive Design**: Works perfectly on both mobile and desktop.

## 🛠️ Tech Stack

- **Frontend**: Next.js 16, React 19, Tailwind CSS
- **Backend**: Express.js, Node.js
- **Database**: MongoDB (via Mongoose)
- **Email Service**: Nodemailer
- **Utility**: Axios, Swiper.js, Lucide React
